# MTMS
This project aims to design and develop a modular robotic system capable of collecting geotagged environmental data across multiple terrain types. The system is built around a shared sensing and computation core that can be attached to different mobility platforms, enabling flexible deployment in land, water, and aerial environments.

The robot will measure key environmental indicators such as:
- Carbon dioxide (CO₂)
- Particulate matter (PM2.5 / PM10)
- Temperature
- Humidity
- Atmospheric pressure
- (Future) Water quality parameters

Collected data will be spatially mapped to identify environmental gradients, pollution hotspots, and microclimate variation.
The project combines robotics, embedded systems, environmental sensing, and geospatial data analysis into a unified engineering system.
